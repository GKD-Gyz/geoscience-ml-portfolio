## 二、调试操作（本周核心技能）

用 `L1_basics/week1_debug.py` 练，步骤如下：

| 动作 | 按键 | 结果 |
|---|---|---|
| 打断点 | 在行号左侧灰区**点一下** | 出现红点 |
| 启动调试 | **F5** | 程序停在断点处，该行变黄 |
| 看变量 | 鼠标悬停在 `total` / `x` 上 | 弹出当前值 |
| 单步跳过 | **F10** | 执行一行，不进入函数 |
| 单步进入 | **F11** | 执行一行，进入函数内部 |
| 继续 | **F5** | 跑到下一个断点 |
| 停止 | **Shift+F5** | 结束调试 |

**本周自查**：能自己设 2 个断点、按 F10 逐行看 `total` 从 0 累加到 12.6，就算过关。
